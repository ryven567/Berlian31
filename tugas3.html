    Website ini membahas tiga teknologi yang banyak digunakan pada era digital, yaitu Internet of Things (IoT), Big Data, dan Cloud Computing.

    IoT menghasilkan data, Big Data mengolah dan menganalisis data, sedangkan Cloud Computing menyediakan sumber daya komputasi dan penyimpanan melalui internet

    Absolute URL

    Absolute URL adalah alamat lengkap yang digunakan untuk menuju suatu halaman atau sumber di internet. contohnya google

    Relative URL

    Relative URL adalah alamat yang digunakan untuk menghubungkan halaman atau file yang berada di dalam website yang sama.

    Contohnya adalah IoT

    Kesimpulan: Absolute URL digunakan untuk mengakses alamat lengkap di internet, sedangkan Relative URL digunakan untuk menghubungkan halaman dalam website sendiri.
