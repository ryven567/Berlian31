Pengertian Cloud Computing

Dengan Cloud Computing.pengguna tidak harus menyimpan seluruh data dan menjalankan seluruh data dan menjalankan seluruh aplikasi hanya pada komputer pribadi. Data dan sumber daya komputer dapat disediakan melalui Internet,sehingga pengguna dapat mengaksesnya dari berbagai perangkat selama terhubung ke jaringan

Contoh layanan Cloud Computing yang sering digunakan dalam kehidupan sehari hari adalah Google Dive,Google Docs,Microsoft OneDrive,dan Dropbox.Layanan tersebut memungkinkan pengguna menyimpan,mengelola,dan mengakses data secara online tanpa harus berghantung sepenuhnya pada penyimpanan komputer

Manfaat Cloud Computing

Cloud computing memungkinkan pengguna untuk mengakses data dari berbagai perangkat selama memiliki koneksi internet. Teknologi ini juga memudahkan pengguna dalam berbagi file dan melakukan pekerjaan secara kolaboratif

Hubungan dengan teknologi lain

Cloud computing dapat digunakan untuk menyimpan dan memproses data yang dihasilkan oleh IoT.Data dalam jumlah besar tersebut juga dapat dianalisi menggunakan teknologi Big Data. Oleh karena itu,IoT,Big data,dan Cloud computing dapat saling mendukung dalam membangun sistem teknologi modern.
